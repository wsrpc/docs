RPCMiddleware
-------------

.. py:class:: RPCMiddleware(app, rpc: RPCApplication, *, path: str='/ws/')

   Route one WebSocket path to RPC and forward other scopes unchanged.

   Install outside a framework to add RPC to any asyncio ASGI application.
   Framework middleware inside this wrapper does not run for the RPC path.
   Put shared authentication outside it or implement ``authorize``.

.. py:data:: STATIC_DIR

   Installed JavaScript clients and TypeScript declarations.

.. py:function:: serializer(value)

   singledispatch wrapped function.
   You might register custom types if you want pass it to the remote side.

   .. code-block:: python

       from wsrpc_asgi import serializer

       class MyObject:
           def __init__(self):
               self.foo = 'bar'

       @serializer.register(MyObject)
       def _(value: MyObject) -> dict:
           return {'myObject': {'foo': value.foo}}
