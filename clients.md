# Clients

Choose the client language independently of the server implementation.

## Python

The [Python client guide](python/clients.md) covers aiohttp and websockets
transports, callbacks and connection lifetimes.

## TypeScript / Node.js

The {ref}`Node client guide <typescript-client>` covers the
typed `@wsrpc/client/node` transport and remote contracts.

## Browser

The [browser client guide](javascript/client.md#browser) covers the existing
`@wsrpc/client`, ESM imports and the classic script build.

Clients share the [WSRPC protocol](protocol.md); API differences are listed
in [compatibility](compatibility.md).
