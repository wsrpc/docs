# Quick start

Choose the language of your application. Each guide contains complete server
and client examples, with tabs for the frameworks available in that language.

```{card} Python
:link: python/quick-start
:link-type: doc

aiohttp, FastAPI, Starlette, Django, Channels, Quart, Litestar, Falcon,
Sanic, BlackSheep and bare ASGI.
```

```{card} JavaScript / TypeScript
:link: javascript/quick-start
:link-type: doc

Node HTTP, Express and Fastify, plus Node.js and browser clients.
```

```{card} Go
:link: go/quick-start
:link-type: doc

net/http server and typed Go client with reverse callbacks.
```

All implementations use the same [protocol](protocol.md). A client can connect
to a server written in another language; see [compatibility](compatibility.md).
